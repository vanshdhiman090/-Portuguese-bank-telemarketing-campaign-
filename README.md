# Bank Campaign Intelligence Dashboard

## Overview
A data analytics case study analyzing 41,188 customer 
records from a Portuguese bank telemarketing campaign.
Built using the Google Data Analytics 6-phase framework.

## Tools Used
- Python (Google Colab) — data cleaning and analysis
- Power BI Desktop — dashboard development
- GitHub — version control and portfolio hosting

## Dataset
UCI Bank Marketing Dataset
https://archive.ics.uci.edu/dataset/222/bank+marketing

## Key Findings
- Overall conversion rate: 11.27%
- Retired and student segments convert 2x above average
- Contacts beyond 5 attempts show near-zero conversion
- Previous campaign success is strongest predictor
